# Rudder Wine Market Intelligence v0.3.9

Screenshot/clipboard-based wine pricing intelligence with improved comparable identity matching, duplicate protection, category reconciliation, and GitHub-backed batch persistence.

Key v0.3.9 change: display names retain winery spelling, but matching is accent-, punctuation-, and case-insensitive. A user may type `Cotes du Robles Blanc` and still match historical `Côtes-du-Rôbles Blanc` records.

See `UPDATE_INSTRUCTIONS.md` for installation details.
